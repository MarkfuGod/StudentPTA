# StudentPTA
My project on ZZU freshman year's C programming course

A terminal program that scores students' PTA lab submissions. Enter each
student's attempts (problem, time, pass, wrong submissions, duplicate rate),
then calculate per-problem scores and a total out of 100.

> [!NOTE]
>
> - _This project runs on `C++ 11`_ and uses ANSI terminal colors (macOS / Linux terminals)
> - ⚒️The **initial `username`** for the program is `MarkfuGod`

## How to run the project
```shell
make        # builds ./student_pta
make run    # builds and runs it
make test   # checks the scoring rules
```
Without `make`:
```shell
g++ -std=c++11 -Iinclude src/*.cpp -o student_pta
```

## Interactive mode
In a terminal the program opens a full-screen, neon-styled interface (needs at
least 66×24; best in a truecolor terminal such as iTerm2):

- **Menus**: `↑` `↓` to move, `Enter` to open, `1`–`5` to jump, `Esc` to go back
- **Input records**: a live score preview updates as you type; after saving,
  the student number is kept and the next problem is selected
- **Report**: animated per-problem bars, total out of 100, and a speed /
  accuracy / originality profile with the student's strength and weakest area
- **Scoring rules**: `←` `→` adjust tier points, `r` resets them

Effects: boot sequence, digital rain, particle bursts, glitches, 3D card-flip
transitions between screens, and a small robot that walks along the bottom,
reacts to what you do, and occasionally says something. Any key skips the boot
sequence; with a window at least 122 columns wide the ZZU logo plays first.
When input or output is not a terminal (pipes, scripts), or with
`STUDENTPTA_PLAIN=1`, it falls back to the original line-by-line prompts.

## Scoring rules
Each problem is scored out of 100, then weighted by difficulty:

```
score = weight[problem] * (time + wrong + duplicate + pass)
```

| Part | Points |
|---|---|
| Time | 25 (≤500s) · 20 (≤1000s) · 10 (≤3000s) · 0 (longer) |
| Wrong submissions | 25 (0) · 20 (1–3) · 10 (more than 3) |
| Duplicate rate | 25 (≤20%) · 20 (≤35%) · 10 (≤50%) |
| Passed | 25 |
| Problem weight | A 0.10 · B 0.15 · C 0.20 · D 0.25 · E 0.30 |

A problem that was not passed, or has a duplicate rate over 50%, scores 0.
The tier points can be changed from menu option 1.
